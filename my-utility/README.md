### Утилита для анализа файлов

Эта утилита анализирует содержимое текстовых файлов и подсчитывает количество целых чисел, чисел с плавающей запятой и строк. Поддерживаются различные режимы работы и опции для сохранения результата.

#### Требования для запуска
Java: 23.0.2 (OpenJDK)  
Система сборки: Gradle 8.12.1  

Установите Gradle  
Проверяем версию  
`gradle -v`  

Клонируем репозиторий  
`git clone git@github.com:kittysontik/my-java-util.git`  
`cd my-java-util/my-utility/`

Собираем jar-файл с Gradle  
`./gradlew build`  

#### Запуск  
`java -jar build/libs/my-utility-1.0-SNAPSHOT.jar in1.txt in2.txt`  

#### Опции  
`-o <путь>`  Указать директорию для сохранения результатов (по умолчанию — текущая папка)  
`-p <префикс>`  Добавить префикс к имени выходного файла  
`-a`  Добавить результаты к существующему файлу    
`-s`  Вывести краткую статистику  
`-f`  Вывести полную статистику  

Пример запуска с флагами  
`java -jar build/libs/my-utility-1.0-SNAPSHOT.jar -f -a -o /Users/kitty/Desktop -p sample- in1.txt in2.txt`
